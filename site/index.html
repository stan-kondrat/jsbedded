Prototype hardware at the speed of JavaScript.

Flash your dev board once. Then edit JS or TypeScript in any editor and run it. No C toolchain, no firmware rebuilds, no waiting. Made for AI-first prototyping.

Get started Read the docs GitHub 
// main.ts: edit, save, run. No firmware rebuild.
const led = board.LED;
let on = false;
gpio.mode(led, "output");

setInterval(() => {
  on = !on;
  gpio.write(led, on ? 1 : 0);
  console.log(on ? "LED on" : "LED off");
}, 500);
Then save main.js to the JSBEDDED USB drive, reset, and it runs.

From zero to running in four steps

The firmware is the only thing you flash. Everything after that is just a script.

  1. Flash onceDrop the ready-made firmware (UF2 for the Pico family) onto your board.
  2. Write main.tsAny editor. Typed APIs from the @jsbedded npm scope.
  3. Save to the USB driveThe board shows up as a drive named JSBEDDED. Save main.js there, reset, and it runs. No rebuild, no reflash.
  4. Read logsSerial logs. A faulty script? Reset button recovers.

Why it's fast, and AI-friendly

The slow part of embedded work is the loop. JSBedded removes it.

No toolchain

No SDKs, CMake or cross-compilers to install. If you can run a script, you can program the board.

No compile phase

Edit, save, run. Your change is on the device in seconds instead of a full firmware rebuild and reflash.

Saves AI tokens

A small script and a typed API instead of build files, HAL code and SDK noise. Less context, fewer wrong turns.

Agent-drivable

Typed APIs, deploy by saving a file, serial logs and recovery: a coding agent can write, run and debug end to end.

Any editor

VS Code, Vim, or your agent. No IDE, vendor tool or account required.

Safe to experiment

A bad script won't brick the board. Reset and you're back to a working device.

Advantages

TypeScript

Typed hardware APIs with autocomplete. One API definition generates the C bindings and the reference docs.

Multi-engine

Pick the JS engine per firmware image to trade size against speed. The API stays the same.

Local-first & private

No account, no cloud dependency, telemetry off by default. MIT licensed.
