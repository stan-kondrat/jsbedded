# Raspberry Pi Pico 2

Facts: `firmware/boards/pico2/board.json`. Status: see the [matrix](../matrix.md).

## Script drive and dev mode

As on the [Pico](./pico.md): USB drive `JSBEDDED` in the last 2 MB of the 4 MB
flash (`DRIVE_KB`), and dev mode by holding BOOTSEL 2 s while the firmware runs.
LED: GP25 (`board.LED`), as on the Pico. Not tested on hardware yet.
